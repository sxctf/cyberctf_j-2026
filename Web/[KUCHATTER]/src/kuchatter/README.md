# CTF Web Challenge: PulseMirror

## Название

PulseMirror

## Категория

Web / XXE

## Сложность

Medium

## Легенда

PulseMirror - внутренний инструмент аналитиков для просмотра публичных соцсетей и импортированных архивов аккаунтов. Команда threat intelligence использует его, чтобы быстро смотреть профили, посты, упоминания и связи между аккаунтами.

Недавно в PulseMirror добавили поддержку старых архивов из корпоративного продукта SocialVault. Эти архивы приходят в XML-формате: профиль, список постов, метаданные аккаунта и связи с другими профилями.

Разработчик сделал импорт "как в старом парсере", чтобы не ломать совместимость с архивами 2015-2018 годов. На ревью это прошло, потому что интерфейс выглядит как обычная соцсеточная аналитика, а импорт архива спрятан в рабочем потоке аналитика.
