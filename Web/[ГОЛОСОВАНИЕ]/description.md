Напишем сюжет мультфильма вместе. Зарегистрированные игроки предлагают продолжение, все желающие (в том числе гости) голосуют за идеи. Каждые пять минут раунд закрывается: победившая реплика дописывается в сюжет, начинается следующий круг.
Голосовать можно без аккаунта: один голос с одного адреса за раунд. Чтобы запостить свою идею, нужна регистрация — слот один на игрока на раунд, до конца голосования идею можно снять. У опубликованной идеи есть скрытый журнал просмотров: автор видит, кто открывал материал по его ссылке.

Сервис перезапускается раз в 60 минут
