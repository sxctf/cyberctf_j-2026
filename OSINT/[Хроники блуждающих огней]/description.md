Серверы лаборатории молчат, но старые полевые записи помнят больше, чем они. Из внешних архивов подняты три фрагментарные записки исследователей — каждая описывает контакт с необъяснимым: огнём без источника, светом без тени, разумом без тела. Даты стёрты, географические названия съедены цензурой и временем — остались только ощущения, детали быта и обрывки свидетельств.

Формат ответа для каждого события: короткий код вида XXXXXX00 (6 значащих символов + два нуля). Символ + в ответе не используется. Флаг — объединение трёх кодов через * в порядке от старого события к новому: flag{код1*код2_код3}.

Формат флага: flag{XXXXXX00_XXXXXX00_XXXXXX00}.
