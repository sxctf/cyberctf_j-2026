# internal-assistant-ru (LoRA)

LoRA-адаптер к `Qwen/Qwen2.5-0.5B` для внутреннего корпоративного ассистента:
дообучен на деловой переписке сотрудников (сообщения на русском).

## Uses
Автодополнение и подсказки в стиле внутренних рабочих сообщений компании.

## Limitations and bias
Небольшая модель — возможны фактические ошибки. Как и любой дообученный адаптер, может
воспроизводить отдельные фрагменты обучающих данных дословно; не применяйте к данным,
которые нельзя раскрывать.
