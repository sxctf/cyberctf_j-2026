# RustWallet Plugin VM (RWVM v1)

Сервис умеет исполнять пользовательские плагины-аналитику. Плагин — это **байткод**
фиксированной виртуальной машины (не нативный код). Вы загружаете программу и
запускаете её:

```
UPLOAD <name> <base64>     # загрузить байткод (base64) → plugins/<name>.bin
PLUGIN <name> [args...]    # исполнить, вернуть вывод программы
```

## Модель данных

Программа работает со стеком `i64` и с массивом **ячеек данных** (`cells`). В ячейках
лежат публичные балансы всех кошельков, упорядоченные по `wallet_id`. Число ячеек
данных возвращает опкод `DLEN` (корректные индексы — `0 .. DLEN`). Вывод программы
(опкоды `OUT`/`OUTB`) возвращается клиенту после `OK`.

## Набор инструкций

| Опкод | Байт | Операнд | Действие |
|-------|------|---------|----------|
| `HALT` | 0x00 | — | стоп |
| `PUSH` | 0x01 | i64 LE (8 б) | положить константу |
| `LOAD` | 0x02 | — | `idx=pop; push cells[idx]` |
| `DLEN` | 0x03 | — | положить число ячеек данных |
| `ADD`  | 0x04 | — | `b=pop; a=pop; push a+b` |
| `SUB`  | 0x05 | — | `b=pop; a=pop; push a-b` |
| `OUT`  | 0x06 | — | `v=pop;` → 8 байт LE в вывод |
| `OUTB` | 0x07 | — | `v=pop;` → младший байт в вывод |
| `DUP`  | 0x08 | — | дублировать вершину |
| `POP`  | 0x09 | — | снять вершину |
| `JMP`  | 0x0A | u16 LE | безусловный переход (абсолютный offset) |
| `JZ`   | 0x0B | u16 LE | `v=pop; if v==0: pc=offset` |
| `SWAP` | 0x0C | — | поменять местами две верхние |

Лимиты: ≤ 200000 шагов, стек ≤ 4096, вывод ≤ 8192 байт.

## Ассемблер

`tools/rwvm.py` собирает текстовый листинг в base64:

```bash
python3 tools/rwvm.py prog.rwa          # → base64 для UPLOAD
python3 tools/rwvm.py prog.rwa -raw > p # → сырые байты
```

Пример — вывести все ячейки данных (`tools/sum_dump.rwa`):

```
  PUSH 0
loop:
  DUP
  DLEN
  SUB
  JZ end
  DUP
  LOAD
  OUT
  PUSH 1
  ADD
  JMP loop
end:
  HALT
```
